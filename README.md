# Display & Audio Switcher

Приложение для удобного переключения между монитором и телевизором с автоматической настройкой звука.

## Возможности

- **Переключение дисплеев**: Быстрое переключение между основным монитором ("Рабочий стол") и телевизором ("Телевизор").
- **Управление звуком**: Переключение режима звука между "Настольный" (2.0) и "Объемный" (5.1).
- **Автоматизация**: При выборе режима "Рабочий стол" звук автоматически переключается в режим 2.0.
- **Автоопределение**: При запуске приложение автоматически определяет текущие настройки монитора и звука.
- **Права администратора**: Приложение автоматически запрашивает права администратора при запуске, необходимые для изменения системных настроек звука.

## Требования

- Операционная система: **Windows**
- Python 3.6 или выше
- Необходимые библиотеки:
  - `pycaw`
  - `comtypes`
  - `pywin32`
  - `Pillow` (для работы GUI, если используется tkinter с изображениями)

## Установка

1. Убедитесь, что у вас установлен Python 3.6+.
2. Установите необходимые зависимости:

```bash
pip install pycaw comtypes pywin32 Pillow
```

## Запуск

Просто запустите скрипт. Приложение автоматически запросит права администратора:

```bash
python display_audio_switcher.py
```

> **Важно**: Для корректной работы приложения необходимо подтвердить запрос на предоставление прав администратора (UAC). Без этих прав изменение конфигурации динамиков (2.0 ↔ 5.1) может быть недоступно.

## Использование

После запуска вы увидите окно с двумя группами элементов управления:

### Группа "Монитор"
- **Рабочий стол**: Переключает вывод изображения на основной монитор (Монитор 1). Автоматически переключает звук в режим 2.0.
- **Телевизор**: Переключает вывод изображения на телевизор (Монитор 2). Звук остается в текущем режиме.

### Группа "Звук"
- **Настольный**: Переключает конфигурацию динамиков в режим 2.0 (стерео).
- **Объемный**: Переключает конфигурацию динамиков в режим 5.1 (объемный звук).

## Как это работает

1. **Определение текущего состояния**: При запуске приложение сканирует подключенные дисплеи и активное аудиоустройство, чтобы отобразить актуальные настройки в интерфейсе.
2. **Переключение монитора**: Использует Windows API для изменения активного дисплея.
3. **Переключение звука**: Использует `pycaw` и COM-интерфейсы Windows для изменения устройства воспроизведения и конфигурации динамиков.
4. **Связь настроек**: Выбор режима "Рабочий стол" автоматически активирует режим звука "Настольный" (2.0), так как это наиболее логичный сценарий использования.

## Решение проблем

- **Приложение не запускается**: Убедитесь, что вы подтвердили запрос прав администратора.
- **Звук не переключается**: Проверьте, что выбрано правильное устройство воспроизведения в настройках Windows. Убедитесь, что ваша звуковая карта поддерживает переключение между 2.0 и 5.1.
- **Монитор не переключается**: Убедитесь, что оба дисплея (монитор и телевизор) подключены и обнаружены системой.
